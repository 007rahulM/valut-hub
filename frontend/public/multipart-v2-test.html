VaultHub Multipart V2 Test

This is a development-only test screen. It does not use the real UploadPage and does not change the old upload code.

What will happen: the page opens a multipart session, asks for permission for one 16 MiB part, sends that part directly to S3, checks the ETag, and aborts the temporary session.

Waiting to start.

What each result means

Session created means the backend and S3 can open the upload.

Part URL created means the backend signed permission for one piece.

Sending to S3 means the browser has left the backend and is sending bytes directly to AWS.

ETag received means the S3 upload and the browser CORS response both worked.

Timeout means the direct S3 request did not finish within two minutes and needs investigation.
